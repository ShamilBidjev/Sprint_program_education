# Приложение «Спринт» (Sprint) — Тренажер быстрых ответов

Добро пожаловать в **«Спринт»** — легкое, современное и интуитивно понятное приложение на ПК для тренировки устного счета и быстрого решения задач. Программа разработана на базе **Python 3** и **PyQt5**, обладает очень простым, минималистичным светлым интерфейсом в приятных индиго-тонах.

---

## 🚀 Основной функционал

1. **Главное лобби (Меню)**
   - **Начать Спринт** — переход к выбору тем и запуску тренировки.
   - **История** — детальный просмотр предыдущих результатов (название темы, дата и время, количество верных ответов, затраченное время в секундах). Возможность полной очистки истории.
   - **Настройки** — регулировка времени (в секундах), которое дается ученику на один спринт. Настройка сохраняется в базе данных.
   - **Шестеренка ⚙️ (в нижнем правом углу)** — защищенный переход в Панель Администратора для добавления/редактирования тем и вопросов.

2. **Проведение Спринта**
   - Ученик выбирает тему из списка (например, стандартные темы *«Дроби 6 класс»*, *«Таблица умножения»* или *«Уравнения 5 класс»*).
   - При запуске вопросы перемешиваются случайным образом, чтобы предотвратить заучивание порядка.
   - На экране отображается текущий вопрос, номер вопроса (например, «Вопрос 3 из 10») и таймер с обратным отсчетом.
   - Ученик вводит ответ в текстовое поле и нажимает кнопку **«Далее →»** (или клавишу `Enter` на клавиатуре).
   - Если время заканчивается, спринт завершается автоматически, фиксируя текущие результаты, а неотвеченные вопросы помечаются как `[время вышло]`.

3. **Результаты**
   - Показывается общая статистика: сколько правильных ответов дано и сколько времени было затрачено.
   - Выводится наглядная таблица детального разбора каждого ответа: текст вопроса, ответ ученика, правильный ответ и цветовой индикатор (зеленая галочка ✅ для верных ответов, красный крестик ❌ для неверных).

4. **Панель Администратора (⚙️)**
   - Предназначена исключительно для учителя/родителя (Админа).
   - **Левая колонка:** Список тем спринтов. Можно мгновенно ввести название новой темы и нажать «Добавить», либо удалить существующую тему со всеми её вопросами.
   - **Правая колонка:** Список вопросов в выбранной теме. Чтобы добавить вопрос, введите его текст (например, `1/2 * 4 = ?`), правильный ответ (например, `2`) и нажмите «Добавить вопрос». Также можно быстро удалять ненужные вопросы.

## 🛠️ Как запустить и собрать в `.exe` на Windows

Мы подготовили специальный исполняемый файл сборщика `build.bat`, чтобы вы могли получить готовый `.exe` в один клик.

### Способ 1. Быстрая сборка в `.exe` (для Windows)
1. Убедитесь, что на вашем компьютере установлен **Python 3** (при установке обязательно поставьте галочку *"Add Python to PATH"* / *"Добавить Python в PATH"*).
2. Скачайте файлы проекта: `sprint_app.py` и `build.bat` в одну папку.
3. Просто дважды кликните по файлу **`build.bat`**.
4. Скрипт сам обновит `pip`, установит `PyQt5` и `PyInstaller` и скомпилирует приложение в единый файл.
5. Готовый файл появится в созданной папке **`dist\Sprint.exe`**. Переместите его в любое удобное место и запускайте на ПК или ноутбуке!

### Способ 2. Запуск как Python-скрипт (из консоли)
Если вы хотите запустить программу напрямую из исходного кода:
```bash
# Установите PyQt5
pip install PyQt5

# Запустите приложение
python sprint_app.py
```

## 📂 Структура проекта

* **`sprint_app.py`** — основной файл программы со всей логикой интерфейса, переключением окон и базой данных.
* **`build.bat`** — автоматический сборщик приложения в `.exe` для операционных систем Windows.
* **`generate_screenshots.py`** — скрипт автоматического тестирования интерфейса, делающий качественные снимки экранов программы.
* **`sprint_data.db`** — локальная база данных SQLite. Создается автоматически при первом запуске программы. В ней хранятся настройки времени, темы, вопросы и история результатов.
* **`screenshots/`** — папка с визуализацией интерфейса приложения (главный экран, опрос, панель админа и т.д.).
